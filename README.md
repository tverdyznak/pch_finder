# ПЧ Finder
Незамысловатый Telegram бот для поиска зеркальных выпусков легендарной телепередачи "Поле Чудес" на Youtube.

## Что вообще делает?
* Просит дату для поиска (например сегодня 2026-01-01)
* Проверит в каких годах была пятница в этот месяц и число (по дефолту с 1998 по 2005 года)
* Попытается найти на Youtube выпуски за пятницы найденные годов (если не найдёт, то попытается найти за радиус в 3 дня)
* Вернёт ссылку для просмотра с кайфом. Ну или не вернёт.

## Как запустить
```bash
git clone https://github.com/tverdyznak/pch_finder.git
cd pch_finder/
docker compose up --build -d
```

Важно переименовать **.env_example** в **.env**, заполнить внутри переменную **TELEGRAM_TOKEN**. 
Ещё там можно выбрать интересующие диапазоны годов. Но можно оставить и дефолтные.

Можно и без Docker запустить в целом:
```bash 
# Активируем окружение
python -m venv env 
source env/bin/activate

# Ставим зависимости
pip install -e requirements.txt

# Применяем переменные
export TELEGRAM_TOKEN=X

# Стартуем бота
python src/bot.py
```

Переменные **START_YEAR** и **END_YEAR** дефолтно 1998 и 2005 соответственно, можно не менять.
